# Institute Automation

A .NET WinForms solution scaffold for a school/institute automation system, 2021.

## About

This repository holds the Visual Studio solution (`FenBilimleriOtomasyon.sln`) and NuGet
dependencies for a planned institute/school automation desktop app ("Fen Bilimleri
Otomasyon" = "Science [Department] Automation" in Turkish). Built in January 2021.

**Note:** the actual project file and source (`.csproj`, `.cs`) were never committed, only
the solution file and its restored packages. This repo is effectively an early scaffold,
not a working application.

## Tech Stack (intended, from committed NuGet packages)

- C# / .NET Framework, WinForms
- Entity Framework 6.2.0 (data access)
- MetroModernUI 1.4.0.0 (UI theme)

## Getting Started

The solution cannot be built as-is since the project source is missing. If you have the
missing `FenBilimleriOtomasyon.csproj` and `.cs` files, open
`FenBilimleriOtomasyon/FenBilimleriOtomasyon.sln` in Visual Studio and restore NuGet
packages.
